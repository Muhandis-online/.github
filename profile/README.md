# Muhandis «مهندس»

Software company that builds business apps and keeps them running, specialising in apps built with AI tools.
We serve businesses and founders in Saudi Arabia and the GCC; the team works remotely.

## Open-source tools

- [rls-check](https://github.com/Muhandis-online/rls-check): a read-only check that explains, in Arabic, which
  database tables anyone can read or change. Runs in the browser, from the command line, as an MCP server and as a
  Claude skill.
- [odx](https://github.com/Muhandis-online/odx): static semantics for real business-system codebases, surfaced
  through thin clients (CLI first).
